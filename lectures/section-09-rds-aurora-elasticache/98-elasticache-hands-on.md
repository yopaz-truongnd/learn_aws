## 1. Kiến thức trọng tâm (Exam Notes)

### 1.1. Các tùy chọn khi khởi tạo ElastiCache trên AWS Console
- **3 Engine lựa chọn:**
  1. **Valkey** (Nhánh thay thế tương thích hoàn toàn với Redis, được AWS khuyến nghị).
  2. **Memcached**.
  3. **Redis OSS**.
- **Deployment option:**
  - **Serverless:** Tự động quản lý dung lượng.
  - **Node-based cluster:** Tự cấu hình loại node, số lượng shards và replicas.
- **Cluster Mode (Chế độ cụm trên Redis / Valkey):**
  - **Disabled:** Chỉ có **1 Shard duy nhất** (gồm 1 Primary node và tối đa 5 Read Replicas).
  - **Enabled:** Hỗ trợ **nhiều Shards (Multiple shards)** phân tán dữ liệu trên nhiều máy chủ.
- **Các cài đặt quan trọng khác:**
  - **Multi-AZ** và **Auto-failover** (tự động chuyển đổi dự phòng khi Primary node gặp lỗi).
  - **Node type:** `cache.t2.micro` hoặc `cache.t3.micro` (thuộc gói Free Tier).
  - **Subnet Group:** Xác định các VPC Subnets nơi đặt các ElastiCache nodes.
  - **Security (Bảo mật):**
    - **Encryption at rest** (Mã hóa dữ liệu lưu trữ bằng KMS key).
    - **Encryption in transit** (Mã hóa đường truyền TLS). Khi bật Encryption in transit, bạn có thể cấu hình **Access Control**: dùng **Redis AUTH** (đặt mật khẩu / AUTH token) hoặc **User Group Access Control List (ACL)** / IAM.
    - **Security Groups:** Kiểm soát truy cập mạng vào cụm Cache.
  - **Backups, Maintenance window & Logs:** Hỗ trợ sao lưu định kỳ và xuất **Slow logs / Engine logs** sang **CloudWatch Logs**.
