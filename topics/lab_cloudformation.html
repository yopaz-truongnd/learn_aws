1) 0-just-ec2.yaml (Tối giản: Chỉ có khối Resources)
--- Resources: MyInstance: Type: AWS::EC2::Instance Properties: AvailabilityZone: us-east-1a ImageId: ami-0453ec754f44f9a4a InstanceType: t3.micro
Khối bắt buộc duy nhất trong CloudFormation
Trong một tệp CloudFormation template, Resources là mục BẮT BUỘC duy nhất. Các mục như Parameters, Mappings, Conditions, Outputs đều là tùy chọn (Optional).
In any CloudFormation template, Resources is the ONLY mandatory section. Sections like Parameters, Mappings, Conditions, and Outputs are all optional.

3. Giải thích các khái niệm cốt lõi & Các bước triển khai Stack 3. Core CloudFormation Concepts & Stack Deployment Steps
Hiểu rõ hàm nội tại !Ref, vòng đời Create/Update/Delete Stack và tính năng Rollback tự động Understanding the !Ref intrinsic function, Create/Update/Delete Stack lifecycle, and automatic Rollback
Hàm nội tại !Ref (Intrinsic Function Fn::Ref) hoạt động thế nào?
• Khi !Ref trỏ tới một Parameter (như !Ref SecurityGroupDescription): Nó trả về giá trị chuỗi mà người dùng đã nhập vào lúc tạo Stack.
• Khi !Ref trỏ tới một Resource (như !Ref MyInstance hoặc !Ref MyEIP): Nó trả về Physical ID của tài nguyên đó (ví dụ Instance ID i-0abc... hoặc địa chỉ IP tĩnh 54.x.x.x), đồng thời báo cho CloudFormation biết phải tạo tài nguyên được tham chiếu trước!
• When !Ref references a Parameter (e.g., !Ref SecurityGroupDescription): It returns the runtime value entered by the user.
• When !Ref references a Resource (e.g., !Ref MyInstance or !Ref MyEIP): It returns the resource's Physical ID (e.g., Instance ID i-0abc... or Elastic IP 54.x.x.x) and implicitly establishes creation order!
Lưu ý về mã ImageId (AMI ID) theo Region
Mã ImageId: ami-0453ec754f44f9a4a và AvailabilityZone: us-east-1a trong template được gắn cứng với Region us-east-1 (N. Virginia). Bởi vì AMI ID là duy nhất theo từng Region, bạn phải chuyển Console sang Region us-east-1 trước khi chạy template này (hoặc dùng SSM Parameter /aws/service/ami-amazon-linux-latest/... trong thực tế).
The ImageId: ami-0453ec754f44f9a4a and AvailabilityZone: us-east-1a are specific to us-east-1 (N. Virginia). Since AMI IDs are Region-scoped, switch your AWS Console to us-east-1 before deploying this template.
