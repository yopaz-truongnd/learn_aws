2. Mã nguồn Hàm Lambda & Cấu trúc Phản hồi Chuẩn Proxy Integration 2. Lambda Function Code & Standard Proxy Integration Response Schema
Tệp nguồn: aws_document/api-gateway/lambda-code.py Source file: aws_document/api-gateway/lambda-code.py
Mã nguồn trong aws_document/api-gateway/lambda-code.py Source code in aws_document/api-gateway/lambda-code.py
import json def lambda_handler(event, context): body = "Hello from Lambda!" statusCode = 200 return { "statusCode": statusCode, "body": json.dumps(body), "headers": { "Content-Type": "application/json" } }
Giải thích chi tiết từng thành phần trong Code Detailed Code Breakdown
Tham số event và context
• event: Đối tượng Python dict chứa toàn bộ dữ liệu HTTP do API Gateway truyền sang: event['httpMethod'], event['headers'], event['queryStringParameters'], event['pathParameters'] và event['body'].
• context: Thông tin môi trường thực thi của hàm Lambda (Function ARN, Request ID, lượng RAM cấp phát, thời gian còn lại trước khi timeout).
• event: A Python dict containing the full HTTP payload passed by API Gateway: event['httpMethod'], event['headers'], event['queryStringParameters'], event['pathParameters'], and event['body'].
• context: Runtime metadata of the Lambda invocation (Function ARN, Request ID, allocated memory, remaining time before timeout).
Tại sao bắt buộc phải dùng json.dumps(body)?
Khi bật Lambda Proxy Integration trên API Gateway, đối tượng trả về của Lambda BẮT BUỘC phải tuân thủ đúng cấu trúc gồm statusCode (số nguyên), headers (dict) và body phải là một chuỗi ký tự (Stringified JSON). Nếu bạn trả về một dict Python trực tiếp trong trường body mà quên bọc json.dumps(), API Gateway sẽ báo lỗi 502 Bad Gateway (Malformed Lambda proxy response)!
With Lambda Proxy Integration enabled on API Gateway, Lambda's return dictionary MUST contain statusCode (int), headers (dict), and body as a serialized string. Returning a raw Python dict in body without json.dumps() triggers a 502 Bad Gateway (Malformed Lambda proxy response) error!

3. Các bước thực hành triển khai Lambda & API Gateway trên AWS Console 3. Step-by-Step Deployment Guide on AWS Console
4 bước từ lúc tạo hàm Lambda đến khi gọi thử API công khai trên trình duyệt 4 steps from creating the Lambda function to invoking the public API endpoint in your browser
  • 1
    Tạo hàm AWS Lambda (Python Runtime) Create the AWS Lambda Function (Python Runtime) Vào AWS Lambda Console → Create function → Author from scratch. Đặt tên hàm (ví dụ my-api-function), chọn Runtime Python 3.12. Trong trình soạn thảo lambda_function.py, dán toàn bộ nội dung file aws_document/api-gateway/lambda-code.py vào và nhấn Deploy. Open AWS Lambda Console → Create function → Author from scratch. Name it my-api-function and choose Python 3.12. Paste the code from aws_document/api-gateway/lambda-code.py into lambda_function.py and click Deploy.
  • 2
    Tạo REST API trên Amazon API Gateway Create a REST API in Amazon API Gateway Mở API Gateway Console → Create API → REST API (Build). Chọn Endpoint Type: Regional. Nhấn Create method (hoặc tạo Resource mới rồi Create method): chọn phương thức GET, Integration type là Lambda Function, bật công tắc Lambda proxy integration và chọn hàm my-api-function. Open API Gateway Console → Create API → REST API (Build). Choose Endpoint Type: Regional. Click Create method: select GET, Integration type Lambda Function, toggle ON Lambda proxy integration, and select my-api-function.
  • 3
    Deploy API ra Stage (Bước bắt buộc để có URL công khai!) Deploy API to a Stage (Required to Publish Changes!) Nhấn nút Deploy API ở góc phải → chọn *New stage* → đặt tên Stage là dev hoặc prod rồi bấm Deploy. (Lưu ý: Mọi thay đổi cấu hình trên API Gateway sẽ không có hiệu lực cho đến khi bạn nhấn Deploy API!) Click Deploy API → select *New stage* → name it dev or prod and click Deploy. (Note: Any changes in API Gateway do not take effect until you explicitly Deploy the API to a Stage!)
  • 4
    Truy cập Invoke URL & Kiểm tra kết quả Open the Invoke URL & Verify Response Sao chép Invoke URL trong mục Stage details (dạng https://xyz.execute-api.us-east-1.amazonaws.com/dev) và mở trên trình duyệt. Bạn sẽ nhận được chuỗi JSON "Hello from Lambda!" với mã HTTP 200. Copy the Invoke URL from Stage details (e.g., https://xyz.execute-api.us-east-1.amazonaws.com/dev) and open it in your browser. You will receive "Hello from Lambda!" with HTTP status 200.
