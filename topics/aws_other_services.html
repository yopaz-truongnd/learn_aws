🚨 4 BẪY TỬ THẦN CẦN NHỚ TRONG PHÒNG THI 🚨 4 DEADLY EXAM TRAPS TO REMEMBER
  • Bẫy 1 — AWS AppSync (GraphQL) vs Amazon API Gateway (REST/WebSocket): Bất cứ khi nào đề thi nhắc đến GraphQL API, đồng bộ dữ liệu ngoại tuyến (Offline data sync) cho mobile apps, hoặc truy xuất dữ liệu từ nhiều nguồn (DynamoDB + Aurora) chỉ với 1 query duy nhất → Chọn ngay AWS AppSync. API Gateway dùng cho REST API hoặc WebSocket thuần túy. Trap 1 — AWS AppSync (GraphQL) vs Amazon API Gateway (REST/WebSocket): Whenever the exam mentions GraphQL APIs, offline data synchronization for mobile apps, or querying multiple data sources (DynamoDB + Aurora) via a single query → Choose AWS AppSync. API Gateway is tailored for standard REST or raw WebSocket APIs.
  • Bẫy 2 — Amazon WorkSpaces vs Amazon AppStream 2.0: WorkSpaces cung cấp toàn bộ màn hình máy tính để bàn ảo (Full Virtual Desktop - Windows/Linux) bền vững cho nhân viên làm việc từ xa, tích hợp Active Directory. AppStream 2.0 chỉ truyền phát trực tuyến một ứng dụng máy tính duy nhất (Single Application Streaming) lên trình duyệt web mà không cần cấp nguyên desktop. Trap 2 — Amazon WorkSpaces vs Amazon AppStream 2.0: WorkSpaces provisions a persistent, full virtual desktop (Windows/Linux) for remote workers with Active Directory integration. AppStream 2.0 streams a single application directly into a web browser without provisioning a full desktop environment.
  • Bẫy 3 — Amazon AppFlow vs AWS Glue: Cần kết nối và truyền dữ liệu 2 chiều giữa các ứng dụng SaaS bên ngoài (Salesforce, Zendesk, ServiceNow, Slack) và AWS (Amazon S3, Redshift) mà không cần viết code (No-code) qua mạng nội bộ bảo mật PrivateLink → Chọn Amazon AppFlow! AWS Glue dùng cho ETL dữ liệu lớn nội bộ trên S3/RDS. Trap 3 — Amazon AppFlow vs AWS Glue: Need a no-code, secure two-way integration between external SaaS apps (Salesforce, Zendesk, ServiceNow, Slack) and AWS (S3, Redshift) privately over PrivateLink → Choose Amazon AppFlow! AWS Glue is tailored for big data ETL across S3 and relational databases.
  • Bẫy 4 — Amazon SES vs Amazon SNS vs Amazon Pinpoint: Amazon SES chuyên gửi email giao dịch (hóa đơn, reset password, marketing hàng loạt) hỗ trợ SMTP. Amazon SNS là dịch vụ pub/sub đẩy thông báo ngắn (SMS, Push, Email alert kỹ thuật). Amazon Pinpoint là nền tảng quản lý chiến dịch tiếp thị (Marketing campaigns, phân khúc người dùng, tin nhắn định kỳ). Trap 4 — Amazon SES vs Amazon SNS vs Amazon Pinpoint: Amazon SES is designed for transactional and high-volume email delivery with SMTP support. Amazon SNS is a pub/sub notification service for system alerts, SMS, and push notifications. Amazon Pinpoint is a marketing campaign platform with user segmentation and engagement analytics.

1. AWS AppSync (GraphQL & Real-time)
Cổng giao tiếp dữ liệu hiện đại cho ứng dụng web và di động Modern data API layer for web and mobile applications
Định nghĩa & Công nghệ:
Dịch vụ quản lý GraphQL API cấp doanh nghiệp. Cho phép ứng dụng chỉ truy vấn chính xác những trường dữ liệu cần thiết (không bị over-fetching hay under-fetching như REST). Hỗ trợ cập nhật dữ liệu thời gian thực (Real-time updates) thông qua WebSockets Subscriptions. Enterprise-level managed GraphQL service. Allows apps to request strictly the specific data fields needed (eliminating over-fetching/under-fetching). Supports real-time updates via WebSockets Subscriptions.
Nguồn dữ liệu hỗ trợ (Data Sources):
AppSync kết nối trực tiếp với nhiều nguồn dữ liệu mà không cần tầng trung gian: 1. Amazon DynamoDB; 2. Amazon Aurora Serverless; 3. Amazon OpenSearch Service; 4. AWS Lambda; 5. HTTP Endpoints bất kỳ. AppSync natively connects to diverse data sources without boilerplate code: 1. Amazon DynamoDB; 2. Amazon Aurora Serverless; 3. Amazon OpenSearch Service; 4. AWS Lambda; 5. Any HTTP endpoint.
Đồng bộ Ngoại tuyến (Offline Data Synchronization):
Tính năng sát thủ cho Mobile Apps: Thiết bị di động có thể đọc và ghi dữ liệu cục bộ khi mất mạng. Khi có kết nối Internet trở lại, AppSync tự động đồng bộ và tự động giải quyết xung đột dữ liệu (Conflict Detection & Resolution). Killer feature for mobile apps: Devices read and mutate local data when offline. Upon reconnecting to internet, AppSync automatically synchronizes and resolves conflicts (Conflict Detection & Resolution).
Bẫy đề thi / Exam Traps:
⚠️ Đề bài thi có từ khóa "GraphQL" hoặc "Offline synchronization for mobile applications" → 100% chọn AWS AppSync (không chọn API Gateway). ⚠️ Question mentions "GraphQL" or "Offline synchronization for mobile applications" → 100% choose AWS AppSync (never API Gateway).

2. Amazon WorkSpaces & AppStream 2.0
Môi trường làm việc ảo từ xa an toàn cho doanh nghiệp Secure enterprise end-user remote computing solutions
Phân định chức năng cốt lõi:
1. Amazon WorkSpaces: Dịch vụ Desktop-as-a-Service (DaaS) cung cấp máy tính để bàn ảo hoàn chỉnh chạy Windows hoặc Linux.
2. Amazon AppStream 2.0: Dịch vụ truyền phát ứng dụng (Application Streaming) đơn lẻ lên trình duyệt HTML5 của người dùng. 1. Amazon WorkSpaces: Desktop-as-a-Service (DaaS) delivering full persistent virtual Windows or Linux desktop environments.
2. Amazon AppStream 2.0: Application streaming service delivering individual desktop applications to HTML5 web browsers.
Tích hợp Doanh nghiệp & Bảo mật:
Cả hai dịch vụ đều chạy trong VPC của bạn và tích hợp sâu với Active Directory (qua AD Connector hoặc AWS Managed Microsoft AD). Dữ liệu doanh nghiệp không bao giờ được lưu trữ trên thiết bị cá nhân của nhân viên, chống thất thoát dữ liệu (DLP). Both services run inside your VPC and integrate natively with Active Directory (via AD Connector or AWS Managed Microsoft AD). Corporate data never leaves AWS to personal client devices, preventing data loss.
Sự khác biệt về Trạng thái Lưu trữ (Persistence):
1. WorkSpaces: Có tính bền vững (Persistent). Dữ liệu, tệp tin và ứng dụng cài đặt được lưu giữ qua các phiên đăng nhập trên EBS volumes.
2. AppStream 2.0: Phi trạng thái (Non-persistent). Mỗi phiên làm việc được cấp phát từ một image cơ sở; khi đóng ứng dụng, phiên làm việc bị hủy bỏ (có thể lưu file ra S3 hoặc Google Drive). 1. WorkSpaces: Persistent. User profile, files, and installed software persist across sessions on dedicated EBS volumes.
2. AppStream 2.0: Non-persistent. Instances are provisioned fresh from a base image and terminated on session close (files saved to S3/Google Drive).
Bẫy đề thi / Exam Traps:
⚠️ Đề bài yêu cầu: Cần cung cấp toàn bộ môi trường desktop hoàn chỉnh cho nhân viên → Chọn WorkSpaces.
⚠️ Đề bài yêu cầu: Cần cho nhà thầu bên ngoài truy cập 1 ứng dụng kế toán cũ mà không cấp desktop → Chọn AppStream 2.0. ⚠️ Question asks: Provide a full virtual desktop experience for employees → Choose WorkSpaces.
⚠️ Question asks: Provide external contractors access to a single legacy accounting app without a desktop → Choose AppStream 2.0.

3. Amazon AppFlow (No-Code SaaS Integration)
Kết nối dữ liệu ứng dụng SaaS hai chiều bảo mật không cần viết code Secure, no-code bi-directional SaaS data transfer integration
Định nghĩa & Bản chất:
Dịch vụ tích hợp dữ liệu được quản lý hoàn toàn cho phép bạn truyền dữ liệu an toàn giữa các ứng dụng Software-as-a-Service (SaaS) như Salesforce, Marketo, Slack, ServiceNow, Zendesk và các dịch vụ AWS như Amazon S3, Amazon Redshift. Fully managed data integration service that securely transfers data between Software-as-a-Service (SaaS) applications (Salesforce, Marketo, Slack, ServiceNow, Zendesk) and AWS services (Amazon S3, Amazon Redshift).
Tính năng Tự động hóa & Lập lịch:
Hỗ trợ 3 cơ chế kích hoạt luồng dữ liệu (Flow Triggers): 1. Chạy theo yêu cầu (On-demand); 2. Chạy theo lịch định kỳ (Scheduled intervals, ví dụ mỗi 1 giờ); 3. Chạy theo sự kiện thực tế (Event-driven, ví dụ khi có Lead mới được tạo trong Salesforce). Supports 3 flow trigger mechanisms: 1. Run on-demand; 2. Run on a schedule (e.g. hourly); 3. Event-driven (e.g. triggered automatically when a new Lead record is created in Salesforce).
Bảo mật tuyệt đối qua AWS PrivateLink:
AppFlow tự động mã hóa dữ liệu khi truyền và khi lưu bằng AWS KMS. Đặc biệt, với các nhà cung cấp SaaS hỗ trợ (như Salesforce), dữ liệu truyền hoàn toàn qua đường mạng riêng AWS PrivateLink mà không bao giờ lộ ra Internet công cộng! AppFlow automatically encrypts data in-transit and at-rest using AWS KMS. Crucially, with supported SaaS providers (like Salesforce), data travels strictly over private AWS PrivateLink connections, never touching the public internet!
Bẫy đề thi / Exam Traps:
⚠️ Đề thi hỏi: Đồng bộ dữ liệu Salesforce với S3/Redshift bảo mật không qua internet và không viết code → Chọn ngay Amazon AppFlow! Không cần viết custom script Python hay Lambda. ⚠️ Question asks: Sync Salesforce data to S3/Redshift securely without internet traversal and without custom coding → Choose Amazon AppFlow! No custom Python/Lambda needed.

4. Amazon SES & Amazon Pinpoint
Giao tiếp khách hàng qua Email giao dịch và Chiến dịch tiếp thị Customer communications via transactional emails & marketing campaigns
Phân định chức năng cốt lõi:
1. Amazon Simple Email Service (SES): Dịch vụ gửi và nhận email cấp doanh nghiệp chi phí thấp phục vụ cho email giao dịch và email thông báo hàng loạt.
2. Amazon Pinpoint: Nền tảng tiếp thị đa kênh (Multi-channel marketing) quản lý chiến dịch tiếp cận khách hàng qua Email, SMS, Push Notifications và Voice. 1. Amazon Simple Email Service (SES): Cost-effective, enterprise-scale inbound and outbound email service for transactional emails and notifications.
2. Amazon Pinpoint: Multi-channel marketing and engagement platform managing campaigns across Email, SMS, Push Notifications, and Voice.
Amazon SES: Gửi & Nhận Email thông minh:
Hỗ trợ giao thức SMTP tiêu chuẩn hoặc gọi qua AWS SDK. Khi nhận email gửi đến domain của bạn, SES có thể kích hoạt quy trình tự động: 1. Lưu email vào Amazon S3; 2. Gọi hàm AWS Lambda để phân tích nội dung; 3. Đẩy thông báo vào Amazon SNS. Supports standard SMTP credentials or AWS SDK API calls. For inbound emails sent to your domain, SES can trigger automated receipt rules: 1. Save email to S3; 2. Execute Lambda function to parse contents; 3. Publish alert to SNS.
Xử lý Tỉ lệ Lỗi (Bounce & Complaint Handling):
SES tích hợp sẵn với Amazon SNS để gửi cảnh báo ngay lập tức khi email bị trả lại (Bounces) hoặc người nhận đánh dấu spam (Complaints). Duy trì tỉ lệ bounce thấp (< 5%) là bắt buộc để tránh bị AWS đình chỉ tài khoản gửi thư. SES integrates natively with Amazon SNS to publish real-time notifications for bounced emails and spam complaints. Maintaining a low bounce rate (< 5%) is mandatory to protect sender reputation.
Bẫy đề thi / Exam Traps:
⚠️ Gửi email thông báo đơn hàng cho khách hàng qua giao thức SMTP → Chọn Amazon SES.
⚠️ Phân khúc khách hàng mục tiêu và gửi tin nhắn đẩy quảng cáo cá nhân hóa theo hành vi → Chọn Amazon Pinpoint. ⚠️ Send order confirmation emails to customers using standard SMTP credentials → Choose Amazon SES.
⚠️ Segment audience target groups and send personalized promotional push notifications → Choose Amazon Pinpoint.

📌 DỊCH VỤ IOT & BATCH 📌 IOT & BATCH COMPUTING
  • AWS IoT Core: Kết nối hàng triệu thiết bị cảm biến thông minh qua giao thức MQTT, HTTP, WebSockets. Sử dụng IoT Rules Engine để lọc và đẩy trực tiếp dữ liệu vào Kinesis, DynamoDB hoặc S3.
  • AWS Batch: Dành cho các công việc xử lý dữ liệu theo mẻ (Batch Jobs). Tự động phân tích yêu cầu RAM/CPU của task trong hàng đợi để khởi tạo EC2 (hoặc Fargate) phù hợp, ưu tiên dùng Spot Instances để tiết kiệm đến 90% chi phí.
💡 QUY TẮC GHI NHỚ TỔNG QUÁT 💡 GENERAL RECOGNITION RULES
  • Mobile Backend as a Service: Nếu đề bài nhắc đến phát triển ứng dụng di động full-stack nhanh chóng → Xem xét AWS Amplify (tự động cấu hình Cognito cho Auth, AppSync cho GraphQL và DynamoDB).
