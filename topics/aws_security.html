🚨 4 BẪY TỬ THẦN CẦN NHỚ TRONG PHÒNG THI 🚨 4 DEADLY EXAM TRAPS TO REMEMBER
  • Bẫy 1 — Giới hạn dữ liệu KMS Encrypt API là 4 KB: Hàm kms:Encrypt chỉ nhận payload tối đa 4 KB. Bất kỳ dữ liệu nào lớn hơn 4 KB (file, database, EBS volume, S3 object) BẮT BUỘC phải dùng Envelope Encryption (Mã hóa phong bì) thông qua API GenerateDataKey. Trap 1 — KMS Encrypt API payload limit is 4 KB: The kms:Encrypt API only accepts up to 4 KB. Any payload larger than 4 KB (files, databases, EBS volumes, S3 objects) MUST use Envelope Encryption via the GenerateDataKey API.
  • Bẫy 2 — Secrets Manager vs SSM Parameter Store: Cần tự động xoay vòng mật khẩu (Automatic Rotation) cho cơ sở dữ liệu (RDS, Aurora, Redshift, DocumentDB) mà không cần cấu hình phức tạp → Chọn Secrets Manager. SSM Parameter Store rẻ hơn nhưng không có built-in rotation (phải tự viết Lambda). Trap 2 — Secrets Manager vs SSM Parameter Store: Need built-in automatic rotation for database credentials (RDS, Aurora, Redshift, DocumentDB) → Choose Secrets Manager. SSM Parameter Store is cheaper but has no native automated rotation out-of-the-box (requires custom Lambda).
  • Bẫy 3 — Tầng bảo vệ WAF vs Shield: AWS WAF bảo vệ ở Tầng 7 (Application Layer - HTTP/HTTPS) chống SQL Injection, XSS, rate-limiting, IP blocking. AWS Shield bảo vệ ở Tầng 3 và 4 (Network & Transport Layer) chống DDoS (SYN Flood, UDP Reflection). Shield Standard miễn phí cho mọi khách hàng; Shield Advanced có đội phản ứng 24/7 SRT và bảo hiểm chi phí. Trap 3 — WAF vs Shield Protection Layers: AWS WAF operates at Layer 7 (Application - HTTP/HTTPS) against SQLi, XSS, rate-limiting, IP blocking. AWS Shield operates at Layer 3/4 (Network/Transport) against DDoS (SYN floods, UDP reflection). Shield Standard is free; Shield Advanced includes 24/7 SRT and DDoS cost protection.
  • Bẫy 4 — Phân biệt GuardDuty vs Inspector vs Macie: GuardDuty phát hiện mối đe dọa thông minh bằng AI từ log (VPC Flow Logs, CloudTrail, DNS). Inspector quét lỗ hổng bảo mật phần mềm (CVEs) trên EC2 và container ECR. Macie dùng AI quét dữ liệu nhạy cảm (PII, số thẻ tín dụng) lưu trên Amazon S3. Trap 4 — Distinguish GuardDuty vs Inspector vs Macie: GuardDuty is intelligent threat detection using AI on logs (VPC Flow, CloudTrail, DNS). Inspector scans software vulnerabilities (CVEs) on EC2 and ECR container images. Macie uses AI to discover sensitive data (PII, credit cards) stored in Amazon S3.

1. AWS Key Management Service (KMS)
Quản lý vòng đời khóa mã hóa tập trung và bảo mật FIPS 140-2 Centralized encryption key management & FIPS 140-2 compliance
Định nghĩa & Phân loại Khóa:
Dịch vụ quản lý khóa mã hóa tập trung. Khóa (KMS Keys) không bao giờ rời khỏi phần cứng bảo mật (HSM) của AWS ở dạng bản rõ. Có 3 loại khóa chính:
1. AWS Owned Keys: Khóa do AWS sở hữu và quản lý ngầm, miễn phí hoàn toàn (ví dụ: SSE-S3).
2. AWS Managed Keys: Khóa mặc định của dịch vụ (tiền tố aws/s3, aws/ebs), miễn phí sử dụng, tự động xoay vòng mỗi 1 năm.
3. Customer Managed Keys (CMK): Khóa do khách hàng tạo ($1/khóa/tháng), toàn quyền kiểm soát Key Policy, audit qua CloudTrail, tùy chọn xoay vòng tự động mỗi 1 năm. Centralized key management service. Key material never leaves AWS HSMs unencrypted. 3 main key types:
1. AWS Owned Keys: Owned by AWS, completely free (e.g. SSE-S3).
2. AWS Managed Keys: Service defaults (prefix aws/s3, aws/ebs), free monthly fee, rotated every 1 year.
3. Customer Managed Keys (CMK): Created by customer ($1/key/month), full control over Key Policy, CloudTrail audit, optional 1-year auto rotation.
Symmetric vs Asymmetric CMK:
1. Symmetric (Đối xứng - AES-256): Khóa mã hóa và giải mã là một; hỗ trợ tích hợp sẵn với toàn bộ dịch vụ AWS; bắt buộc dùng cho Envelope Encryption.
2. Asymmetric (Bất đối xứng - RSA/ECC): Có Public Key (mã hóa hoặc verify signature) và Private Key (giải mã hoặc sign); dùng khi cần chia sẻ Public Key cho đối tác bên ngoài AWS không có tài khoản AWS. 1. Symmetric (AES-256): Same key encrypts and decrypts; seamlessly integrated across all AWS services; mandatory for Envelope Encryption.
2. Asymmetric (RSA/ECC): Public Key (encrypt/verify signature) and Private Key (decrypt/sign); ideal for sharing public key with outside partners without AWS accounts.
Multi-Region Keys & Key Rotation:
1. Multi-Region Keys: Cho phép nhân bản khóa KMS từ Primary Region sang Replica Region với cùng Key ID và cùng key material. Cho phép mã hóa ở us-east-1 và giải mã tại eu-west-1 mà không cần gọi API xuyên vùng.
2. Automatic Rotation: Khi bật xoay vòng khóa, AWS tạo phiên bản key material mới; key material cũ vẫn được lưu giữ an toàn để giải mã dữ liệu lịch sử. 1. Multi-Region Keys: Replicates KMS keys from Primary Region to Replica Regions with the identical Key ID and key material. Encrypt in us-east-1 and decrypt in eu-west-1 without cross-region API calls.
2. Automatic Rotation: Backing key material changes annually; previous key material is preserved to decrypt older ciphertexts.
Bẫy đề thi / Exam Traps:
⚠️ IAM Policy một mình là KHÔNG ĐỦ để cấp quyền KMS! Bắt buộc phải có KMS Key Policy cho phép IAM entity đó truy cập.
⚠️ Để cross-account dùng KMS, phải cấp quyền trong KMS Key Policy ở Account A VÀ cấp IAM Policy ở Account B. ⚠️ An IAM Policy alone is INSUFFICIENT for KMS access! The KMS Key Policy must explicitly permit the IAM principal.
⚠️ For cross-account KMS usage, grant permissions in Account A's Key Policy AND Account B's IAM Policy.

2. SSM Parameter Store vs Secrets Manager
Lựa chọn kho lưu trữ cấu hình và thông tin xác thực tối ưu Choosing optimal config and credential storage
Định nghĩa & Bản chất:
1. AWS Systems Manager Parameter Store: Kho lưu trữ cấu hình dạng phân cấp (hierarchical key-value). Hỗ trợ String, StringList, và SecureString (mã hóa bằng KMS).
2. AWS Secrets Manager: Dịch vụ chuyên dụng quản lý thông tin mật (database passwords, API keys, OAuth tokens) với khả năng tự động xoay vòng mật khẩu thông qua AWS Lambda. 1. AWS Systems Manager Parameter Store: Hierarchical key-value configuration storage. Supports String, StringList, and SecureString (KMS encrypted).
2. AWS Secrets Manager: Dedicated secrets management service (database credentials, API keys) with built-in automated rotation via AWS Lambda.
So sánh tính năng xoay vòng (Rotation):
1. Secrets Manager: Tích hợp sẵn cơ chế Automatic Rotation theo lịch định kỳ (ví dụ mỗi 30 ngày) cho Amazon RDS, Aurora, DocumentDB, Redshift mà không làm gián đoạn ứng dụng.
2. SSM Parameter Store: KHÔNG có cơ chế xoay vòng tự động tích hợp sẵn (muốn xoay vòng phải tự tích hợp EventBridge + Lambda viết tay). 1. Secrets Manager: Built-in scheduled automated rotation (e.g. every 30 days) natively supporting Amazon RDS, Aurora, DocumentDB, Redshift without app downtime.
2. SSM Parameter Store: NO native automated rotation (requires custom EventBridge + Lambda scripting).
Mô hình Chi phí (Cost Model):
1. SSM Parameter Store: Standard Tier hoàn toàn Miễn phí (tối đa 10,000 parameters, kích thước 4 KB). Advanced Tier ($0.05/10,000 params, 8 KB).
2. Secrets Manager: Có phí $0.40 / secret / tháng + $0.05 / 10,000 API calls. 1. SSM Parameter Store: Standard Tier is completely Free (up to 10,000 parameters, 4 KB size limit). Advanced Tier is $0.05/10,000 params (8 KB size).
2. Secrets Manager: Costs $0.40 per secret per month + $0.05 per 10,000 API calls.
Bẫy đề thi / Exam Traps:
⚠️ Đề bài yêu cầu: "Chi phí thấp nhất để lưu trữ cấu hình và license keys" → Chọn SSM Parameter Store Standard.
⚠️ Đề bài yêu cầu: "Tự động đổi mật khẩu cơ sở dữ liệu RDS định kỳ" → Chọn AWS Secrets Manager. ⚠️ Question asks: "Lowest cost solution for config strings and license keys" → Choose SSM Parameter Store Standard.
⚠️ Question asks: "Automatically rotate RDS database credentials on a schedule" → Choose AWS Secrets Manager.

3. AWS WAF & AWS Shield
Lá chắn bảo vệ ứng dụng Web và hạ tầng mạng chống tấn công DDoS Web application firewall & DDoS infrastructure protection
Định nghĩa & Phạm vi bảo vệ:
1. AWS WAF (Web Application Firewall): Bảo vệ ở Tầng ứng dụng (Layer 7 HTTP/HTTPS) chống lại các lỗ hổng web phổ biến (OWASP Top 10).
2. AWS Shield: Dịch vụ bảo vệ chống tấn công từ chối dịch vụ phân tán (DDoS) bảo vệ hạ tầng mạng và giao vận (Layer 3 & Layer 4). 1. AWS WAF: Operates at the Application Layer (Layer 7 HTTP/HTTPS) filtering malicious web traffic against OWASP Top 10 vulnerabilities.
2. AWS Shield: Managed DDoS protection safeguarding network and transport layers (Layer 3 & Layer 4).
Dịch vụ tích hợp (Integration Points):
1. AWS WAF gắn vào: Application Load Balancer (ALB), Amazon CloudFront, Amazon API Gateway, AWS AppSync, Amazon Cognito User Pools.
2. AWS Shield Standard: Tự động kích hoạt mặc định trên toàn bộ CloudFront, Route 53, ALB, EC2 miễn phí.
3. AWS Shield Advanced: Bảo vệ nâng cao cho CloudFront, Route 53, Global Accelerator, ALB, Elastic IPs. 1. AWS WAF integrates with: Application Load Balancers (ALBs), Amazon CloudFront, Amazon API Gateway, AWS AppSync, Amazon Cognito User Pools.
2. AWS Shield Standard: Automatically enabled by default across all CloudFront, Route 53, ALBs, and EC2 for free.
3. AWS Shield Advanced: Advanced mitigation for CloudFront, Route 53, Global Accelerator, ALBs, and Elastic IPs.
Quy tắc WAF (Web ACL Rules):
Hỗ trợ lọc traffic theo: Địa chỉ IP (IP sets), Quốc gia (Geo-match), Chuỗi độc hại (SQLi, XSS), Rate-based rules (giới hạn tần suất request từ 1 IP để chống brute force/DDoS L7), và AWS Managed Rules (bộ quy tắc được cập nhật liên tục bởi AWS). Web ACL rules filter traffic by: IP address sets, Geo-matching (country blocking), String/Regex match (SQLi, XSS), Rate-based rules (throttle IPs exceeding threshold), and AWS Managed Rulesets.
Bẫy đề thi / Exam Traps:
⚠️ Muốn chặn tấn công Layer 7 HTTP flood (như 10,000 requests/giây từ botnet) → Dùng AWS WAF Rate-based Rule kết hợp CloudFront.
⚠️ Cần bảo hiểm chi phí khi bị DDoS quy mô lớn → Chọn AWS Shield Advanced (DDoS Cost Protection). ⚠️ To mitigate Layer 7 HTTP flood attacks (e.g. 10,000 req/sec botnet) → Use AWS WAF Rate-based Rules with CloudFront.
⚠️ Need financial reimbursement for auto-scaling cost spikes during DDoS → Choose AWS Shield Advanced.

4. AI Security Triad: GuardDuty, Inspector & Macie
Bộ ba an ninh thông minh tự động hóa phân tích mối đe dọa bằng Machine Learning Automated ML-powered threat detection, vulnerability scan & data privacy
Phân định chức năng cốt lõi:
1. Amazon GuardDuty: Dịch vụ phát hiện mối đe dọa thông minh (Threat Detection) theo thời gian thực.
2. Amazon Inspector: Dịch vụ quét lỗ hổng phần mềm tự động (Vulnerability Management) theo mã CVE.
3. Amazon Macie: Dịch vụ bảo mật dữ liệu nhạy cảm (Data Security & Privacy) trên Amazon S3. 1. Amazon GuardDuty: Real-time intelligent Threat Detection service.
2. Amazon Inspector: Automated software Vulnerability Management service based on CVEs.
3. Amazon Macie: Sensitive Data Security & Privacy discovery service on Amazon S3.
Nguồn dữ liệu & Đối tượng quét:
1. GuardDuty: Phân tích VPC Flow Logs, DNS Query Logs, CloudTrail Management Events, CloudTrail S3 Data Events, EKS Audit Logs (hoàn toàn không cần cài agent).
2. Inspector: Quét hệ điều hành EC2 (thông qua SSM Agent), quét container images trên Amazon ECR, và quét mã nguồn Lambda Functions.
3. Macie: Quét các bucket S3 để tìm thông tin PII (Personally Identifiable Information), số an sinh xã hội, số hộ chiếu, thẻ ngân hàng. 1. GuardDuty: Analyzes VPC Flow Logs, DNS Logs, CloudTrail Management/S3 Data Events, EKS Logs (agentless).
2. Inspector: Scans EC2 OS packages (via SSM Agent), Amazon ECR container images, and Lambda function code.
3. Macie: Scans S3 buckets for PII (Personally Identifiable Information), SSNs, passport numbers, and credit cards.
Cơ chế Tự động hóa Phản ứng (Automated Remediation):
Cả 3 dịch vụ đều gửi kết quả cảnh báo (Findings) sang Amazon EventBridge. Từ EventBridge, có thể kích hoạt AWS Lambda để tự động cách ly EC2 nhiễm mã độc, cập nhật Security Group, hoặc gửi cảnh báo SNS cho Security Team. All 3 services emit event findings to Amazon EventBridge, which can trigger AWS Lambda for automated remediation (e.g. isolating compromised EC2, patching SG, or sending SNS alerts).
Bẫy đề thi / Exam Traps:
⚠️ GuardDuty KHÔNG ngăn chặn cuộc tấn công; nó chỉ phát hiện và cảnh báo! Muốn tự động chặn, phải kết hợp GuardDuty → EventBridge → Lambda/WAF.
⚠️ Inspector chỉ quét lỗ hổng ứng dụng và cấu hình mạng của EC2/ECR; không phân tích hành vi mạng bất thường (đó là việc của GuardDuty). ⚠️ GuardDuty DOES NOT block attacks natively; it only detects and alerts! Automated blocking requires GuardDuty → EventBridge → Lambda/WAF.
⚠️ Inspector only scans package CVEs and network reachability; it does not analyze network anomalies (that is GuardDuty).

  • Xoay vòng khóa không làm hỏng dữ liệu cũ: Khi KMS Key xoay vòng, dữ liệu đã mã hóa không cần giải mã và mã hóa lại ngay. AWS lưu trữ backing key cũ để giải mã.
  • Cross-account KMS: Cần cả 2 điều kiện: Key Policy ở tài khoản sở hữu cho phép + IAM Policy ở tài khoản sử dụng cho phép.
  • Xóa khóa KMS có độ trễ an toàn: KMS Key không thể xóa ngay lập tức; thời gian chờ bắt buộc (Waiting Period) từ 7 đến 30 ngày.
💡 QUY TẮC PHÒNG THỦ MẠNG & DỮ LIỆU 💡 NETWORK & DATA DEFENSE RULES
  • Defense in Depth: Kiến trúc chuẩn AWS luôn đặt WAF tại CloudFront/ALB → Security Groups tại EC2/Fargate → KMS tại Storage → GuardDuty giám sát tổng thể.
  • Tự động phản ứng sự cố: Mô hình chuẩn là Dịch vụ phát hiện (GuardDuty/Inspector/Config) → EventBridge Rule → AWS Lambda tự động cô lập/sửa chữa.
  • Phân biệt Secrets: Mật khẩu Database → Secrets Manager. Cấu hình ứng dụng, string URLs, API endpoints không cần tự xoay vòng → SSM Parameter Store.
