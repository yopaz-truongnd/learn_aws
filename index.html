All 86 vocabulary terms are grouped into 5 Units (20 words each) and packaged directly into dist/AWS_SAA_C03_Vocabulary.apkg matching Note Type 4000Book1: card numbering, fill-in hints t__ __ __ __n, type-in spelling check (green for correct, red for incorrect), IPA phonetics, and direct Udemy timestamp lecture links.

Cách 1: Nhấp đúp mở ngay (Khuyên dùng) Method 1: Double-click to Open (Recommended)
Chỉ cần nhấp đúp trực tiếp vào file dist/AWS_SAA_C03_Vocabulary.apkg trong thư mục dự án. Phần mềm Anki trên máy tính sẽ tự động mở và tạo deck "AWS SAA-C03 Vocabulary (Stephane Maarek)" với đầy đủ giao diện, màu sắc và tính năng gõ từ kiểm tra.
Simply double-click dist/AWS_SAA_C03_Vocabulary.apkg in the project folder. Anki Desktop will launch and import the "AWS SAA-C03 Vocabulary (Stephane Maarek)" deck with full styling, colors, and type-in recall.
Cách 2: Import file TSV 11 cột Method 2: Import 11-column TSV File
Nếu bạn muốn đưa vào bộ thẻ có sẵn của mình, vào Anki chọn File → Import... và chọn file dist/anki_4000_format.tsv (ánh xạ đủ 11 trường: №, Keyword, Suggestion, Short Vietnamese, Sound, Image, Transcription, Explanation, Full Vietnamese).
To merge into an existing deck, open Anki, choose File → Import... and select dist/anki_4000_format.tsv (maps 11 fields: №, Keyword, Suggestion, Short Meaning, Sound, Image, Transcription, Explanation, Full Meaning).
